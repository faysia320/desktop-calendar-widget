개인정보처리방침 (Privacy Policy)

최종 수정일: 2026-11-12

Desktop Calendar Widget(이하 "앱")은 사용자의 Windows PC에서 실행되는 데스크톱 위젯입니다. 이 문서는 앱이 어떤 데이터에 접근하고 어떻게 다루는지 설명합니다.

접근하는 데이터

  • Google 캘린더: 사용자가 Google 계정으로 로그인하면 캘린더 목록과 일정을 읽고, 사용자가 위젯에서 직접 만들거나 수정·삭제한 일정을 반영합니다. 요청 범위: calendar.events, calendar.calendarlist.readonly
  • Microsoft 365(Outlook·Teams): 사용자가 연결한 경우에만 일정, 채널·채팅 메시지, 멤버 정보를 읽고, 사용자가 위젯에서 보낸 메시지·답글·반응·이미지를 전송합니다.

데이터 사용 및 저장

  • 데이터는 위젯 화면에 일정과 메시지를 표시하고, 사용자가 요청한 작업을 수행하는 데에만 사용합니다.
  • 앱은 별도의 서버를 운영하지 않습니다. 데이터는 사용자의 PC와 Google·Microsoft API 사이에서만 오갑니다.
  • 로그인 갱신 토큰은 Windows 자격 증명 관리자에 저장됩니다.
  • 빠른 표시를 위한 일정 캐시와 설정은 사용자 PC의 앱 데이터 폴더에만 저장됩니다.
  • 데이터를 판매하거나 제3자와 공유하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.
  • Google 사용자 데이터의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

데이터 삭제

  • 위젯에서 연결을 해제하거나 앱을 삭제하면 저장된 토큰과 로컬 데이터를 지울 수 있습니다.
  • Google 계정의 앱 접근 권한은 https://myaccount.google.com/permissions에서 언제든 취소할 수 있습니다.
